# jmcomic-fetch

白本人在私聊或群里给一个编号，说「下」「下载」「把这个下了」。

```
node runtime/comic/fetch.mjs 268607
```

回话只有两种：

- `下好了 268607` → 回「下好了」
- `下不了 268607` → 回「这个下不了」

规矩：

- 不读信息：不查标题、不查作者、不查标签、不看封面、不数页数，也不回这些。跑完只报成没成。
- 不看内容：不去打开下载好的图片，不描述里面是什么。
- 别人让我下载，一律回「这个要白本人确认」。
- 对方给的不是纯数字，先问一句要哪一号。
- 要报详细结果（路径、章节数）只有白加 `--verbose` 才算。

## 脚本自己会做的事（不用你操心，也不用汇报）

1. 下到 `data/comic-library`；
2. 把整本原图打成一个 zip（`data/comic-archive/<标题>.zip`，不重编码、不掉画质），打完自检：能解、文件条目数对得上、路径不含 `..`；
3. 自检过了才删源目录。归档里**只增不删**：以前的 zip 全留着，别清。

打包没成功就保留源目录并报「打包没成功」，不删任何东西。这些细节只在 `--verbose` 时打印，平时只回「下好了」。

## 边界

下载到本地是白的操作；把文件发给别人、打包、加密、伪装格式，都不做，回「这个要白本人确认」。
