# jmcomic-title

有人给一个编号（1~7 位数字，比如 268607），问「这是哪本」「查一下」。

```
node runtime/comic/title.mjs 268607
```

出来就两行：

```
268607｜<标题>
作者 <作者名>
```

## 规矩

- 只读标题和作者。标签、页数、封面图、简介、赞数、浏览数，一律不读、不报、不猜。
- 谁问都查：私聊、群里被 @ 都行。这不算「外人通道」里要拒的事——不读文件、不给凭证、不发链接。
- 回的时候只回那一两行，不解释我跑什么命令、不报路径。
- 查不到就回「这个编号查不到」。要登录才看得到的，回「这本要登录才能看」。
- 不贴封面、不转图、不给下载链接。
- 要下载是另一件事，只有白本人能提，走 `jmcomic-fetch`。
